# Prompt log — Bài thực hành Tuần 3

## Prompt 1

Tạo một trang portfolio cá nhân dùng CSS Grid cho bố cục tổng thể gồm Header, Sidebar, Main Content và Footer. Header và Footer phải trải toàn bộ chiều rộng. Giao diện hiện đại, semantic HTML và không dùng float.

## Prompt 2

Dùng Flexbox cho navigation, danh sách kỹ năng và footer. Danh sách kỹ năng cần `flex-wrap: wrap` và dùng `gap` thay cho margin thủ công giữa các item.

## Prompt 3

Tạo Project Gallery tối thiểu 6 item bằng CSS Grid. Các thẻ cần đồng đều, responsive trên tablet/mobile, có hover state nhưng vẫn tôn trọng `prefers-reduced-motion`.

## Prompt 4

Kiểm tra CSS Grid để tránh tràn ngang hoặc chồng lấn ở màn hình nhỏ. Chuyển layout hai cột thành một cột dưới 900px và gallery thành một cột dưới 620px.

## Prompt 5

Tạo trang minh họa cho hoạt động "Flex & Grid Battle": căn giữa một phần tử bằng Flexbox, tạo menu dàn đều bằng `justify-content: space-between`, và tạo gallery 3 cột bằng CSS Grid. Giải thích ngắn gọn lý do chọn từng kỹ thuật.

## Prompt 6

Debug và refactor CSS: sửa tiêu đề tiếng Việt bị chồng dấu bằng cách điều chỉnh `line-height`, `letter-spacing` và `clamp()`; loại bỏ kỹ thuật dàn trang dư thừa; bảo đảm responsive ở các breakpoint nhỏ.
